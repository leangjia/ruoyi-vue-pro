### Task 1: Convert MES DDL from H2 to MySQL syntax

**Files:**
- Read: `D:\opencodeproject\ruoyi-vue-pro\yudao-module-mes\src\test\resources\sql\create_tables.sql`
- Create: `D:\opencodeproject\ruoyi-vue-pro\sql\mysql\mes_create_tables.sql`

- [ ] **Step 1: Read the MES create_tables.sql file**

- [ ] **Step 2: Convert H2 syntax to MySQL syntax**

The H2 file uses these patterns that need conversion:
| H2 | MySQL |
|---|---|
| `GENERATED BY DEFAULT AS IDENTITY` | `AUTO_INCREMENT` |
| `"table_name"` (double-quoted identifiers) | `` `table_name` `` (backtick identifiers) |
| `timestamp DEFAULT NULL` | `datetime DEFAULT NULL` (or keep `timestamp`) |
| `bit NOT NULL DEFAULT FALSE` | `tinyint(1) NOT NULL DEFAULT 0` |
| `bit DEFAULT FALSE` | `tinyint(1) DEFAULT 0` |
| No `ENGINE=InnoDB` | `ENGINE=InnoDB DEFAULT CHARSET=utf8mb4` |

For `DECIMAL` types, keep as-is (MySQL supports `DECIMAL`).

For `LONGTEXT` entries in the original → keep as `LONGTEXT`.

- [ ] **Step 3: Write the MySQL DDL file**

The converted SQL file should:
- Use `IF NOT EXISTS`
- Use backtick quoting
- Use `AUTO_INCREMENT` for primary keys
- Use `ENGINE=InnoDB DEFAULT CHARSET=utf8mb4 COLLATE=utf8mb4_unicode_ci` at the end of each CREATE TABLE
- Add `DROP TABLE IF EXISTS` before each CREATE (optional, for re-runnability)

- [ ] **Step 4: Verify the converted SQL is valid**

Check that:
- No `GENERATED BY DEFAULT AS IDENTITY` remains
- All identifiers use backticks
- All CREATE TABLE statements end with `ENGINE=InnoDB DEFAULT CHARSET=utf8mb4`
